# 统一库存状态：谁维护、谁读取

`comfyui-model-library`维护派生文件`<资料库>/索引数据/model-locality-index.json`。正式模型卡保存来源和用途，库存文件保存当前路径状态；旧版/远端卡不必搬目录或删除。skill不是后台程序：由执行本技能的代理在任务内调用刷新工具。

## 维护动作

在用户授权的模型维护任务中，文件增删移动改名、补录本地路径或批量发布模型卡后，先完成原有身份和引用核对，再运行一次：

```text
python scripts/inventory_state.py refresh <资料库根> --models-root <模型根> --quarantine-root <已明确的隔离根>
```

隔离参数可省略或重复。刷新只枚举文件名/目录并检查元数据，不读取权重内容，不下载、移动、删除模型，也不代替原来的SHA核验与正式卡发布。新文件未登记时列入`unregistered_paths`；由本技能查证身份并补卡后再次刷新，不能只按文件名自动绑定。

只读查询可用`show`或`shared_model_library.py query`，不运行refresh写状态。普通卡片查询返回的`status=matched`只表示知识匹配，必须另看返回条目的`inventory`。

## 读取契约

- `local_unique`：模型根内只有1个已登记现存路径；`local_multiple`：多个已登记现存路径。
- `not_local`：没有现存本地路径，可能是未下载候选或历史卡；不猜它以前是否下载过。
- `quarantined`／`outside_root`：隔离保留或模型根外；不当成可加载的本地模型。
- `path_missing`：已登记路径失效；需处理文件或修正登记。
- `stale`／`unknown`：库存过期、缺失或无效；不能继续称已安装、唯一或可清理。

“本地1份”仅指已登记路径数，不代表全盘无副本、SHA内容去重证明或功能独一无二。`content_hash_rechecked=false`明确本次库存刷新没有重算权重SHA。

读取方使用`inventory_state.read_state`，检查`fresh`和每项`is_local`、`eligible_for_local_cleanup`，而不是资料卡总数、目录名称或旧`local_binding_status`。同一个模型的本地文件与非本地版本分别投影：本地比较主表只收现存项；只有一件本地文件的单列保留；旧版/下载候选放参考区。

`eligible_for_local_cleanup`仅表示可以纳入本地清理审查，不是删除授权，也不证明文件冗余。内容去重仍需完整SHA，功能精简仍需明确取舍及用户授权。

读取器只读取JSON及检查已记录路径/目录的stat元数据，不枚举目录、不打开权重、不写状态。模型索引变更、已知文件改动/消失或目录新增删除造成元数据变化时，返回待刷新并停止肯定本地标记。不是文件系统常驻监听；新下载或未知改名需维护任务登记，节点“重读资料与库存”不等于离线重扫或重算SHA。

## 下游与部署

模型查询、工作流skill和中文模型卡节点共用此脚本的读取逻辑。主实现只维护在本技能`scripts/inventory_state.py`；节点和工作流skill随部署带同内容的读取副本，不另写判定规则。变更读取契约时同步这些副本并校验SHA。

修改后验证：本地/非本地/隔离不混用；移动或删除文件后旧快照不能保持有效；索引更新后需刷新；只读查询不写文件；知识匹配不能被当作安装匹配；当前文档完整重生成后，非本地项不能回到清理主表。保持原本“不加载权重、不提交生成”的节点约束。
