# Performance / Dialogue / Action

## Performance core

基本链：attention → receive → choose → playable action → visible response → residue。

“伤心、愤怒、紧张”不是足够的表演指令。需要知道角色在争取什么，以及收到什么刺激后改变策略。

## Character profile

可维护 posture/gait、gaze habit、gesture+trigger、voice identity、mask、break condition、under-pressure behavior。

长期 profile 与当前 scene state 分开。

## Dialogue performance

按需设计 floor ownership、pickup、interruption、overlap、failed start、self-correction、silence、trigger word、listener reaction。

声音身份和当前说话状态分开：同一个角色可以在不同场次里冷静、喘息、压低声音或失去控制。

## Action geometry

重要动作至少明确 purpose、start state、initiator、target、path、contact/block/miss、force direction、response、position change、end state。

## Fight / chase

先保证距离、攻防、路径、持物、环境、受力、可读性，再考虑特定招式或运镜。

Recipe 可以提供拳法、剑法、轻功、大招、粒子效果，但不能替代动作因果。

## Group performance

群像避免所有人同步反应。每个角色应有当前任务、attention target、反应延迟和独立行为。

## Scale discipline

表演细节必须匹配景别和时长。看不见的手指微动不应写进超远景；5秒镜头不能塞入五次独立策略变化。
