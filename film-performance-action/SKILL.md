# Performance & Action

按需读取[表演、对白与动作方法](references/performance-action.md)和[Recipe Library](references/recipe-library.md)；来源见[Sources](references/sources.md)。

## 表演核心

```text
objective
→ receive
→ choose
→ playable action
→ visible reaction
→ residue
```

“悲伤”“愤怒”“紧张”不能单独作为表演指令。

## Performance Bible

### Character profile
- posture / gait；
- gaze habit；
- gesture + trigger；
- voice identity；
- mask / break condition；
- what this person does when under pressure。

### Scene adaptation
- current objective；
- tactic；
- what line/action changes them；
- gaze target；
- body tension；
- breath/pause；
- what remains after the beat。

## Dialogue Performance

长对白/争吵按需设计：

- current floor / 话权；
- planned pickup；
- interruption；
- overlap；
- failed start；
- self-correction；
- silence；
- trigger word；
- listener reaction。

不要平均添加口吃、停顿、眨眼。

## Action

每个重要动作至少明确：

- purpose；
- start body/prop state；
- initiator；
- target；
- path；
- contact / block / miss；
- force direction；
- response；
- position change；
- end state。

## Fight / Chase

优先：

- 距离；
- 身体占用；
- 武器/道具；
- 攻防；
- 环境；
- 位置变化；
- action readability。

Recipe Library 可以提供拳法、剑法、轻功、大招、特效，但不能替代上述因果结构。

## 生成风险

遇到：

- 多人复杂接触；
- 精细手部操作；
- 长时间物件遮挡；

向 Production Supervisor 报风险，不自行把动作改成另一件事。

## 禁止

- 不规定 camera/lens 为本职责所有。
- 不把“电影慢动作/360环绕”写成动作本体。
- 不用招式数量代替戏剧变化。
- 不把 Provider 失败经验写成所有媒介的表演规则。
