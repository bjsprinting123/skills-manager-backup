# Post-production Craft

## Picture Edit

完整看实际素材，记录 usable range、bad head/tail、action completion、drift、dialogue region、reaction，再决定 in/out、镜序、J/L cut、match、bridge、omit。

剪辑可以取舍素材，但不能悄悄改台词含义或故事事实。

## Sound Post

分 Dialogue/ADR、Room Tone、Ambience、Foley、Spot SFX、Music、Intentional Silence。

Sound Bible 是上游创作决定；后期实现它，不重新发明故事。

## VFX / Compositing

VFX Shot List 可分 cleanup、roto/mask、tracking、screen/text replacement、environment layer、character/body patch、transition/seam repair。

无法后期可靠解决的错误返回 Shot/Production。

## Color

Visual Bible / Color Script 是上游。后期负责 technical transform、shot matching、exposure/balance、saturation/contrast、approved grade、delivery transform。

## Titles / Subtitles / Graphics

字幕文字来自 accepted screenplay；屏幕/UI文字来自已接受 Graphics Spec。不要让生成模型随机重写。

## Master QC

technical_valid、creative_review、sequence_review、user_acceptance 四个状态独立。

## Delivery

记录 version、resolution、fps、aspect、codec/container、color space、audio layout、loudness target、subtitle mode、duration、source cut、unresolved notes。
