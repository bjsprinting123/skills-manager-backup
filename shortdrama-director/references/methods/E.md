# E 声音与时间（9卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| E01 | 谁发声、在哪里、谁接收、起什么作用 | 转写、字幕、用户听辨和实际音轨分别记证据 |
| E01a | 根据声源、听点、录音/混音意图安排远近与清晰度 | 远景也可有清晰对白；焦距和景别不直接规定最终音量 |
| E01b | 画外声方位、距离与人物回应 | 声源不必入画；声音方向与转头关系有依据 |
| E01c | 关键音效与接触/启停事件对应 | 数量按需求，不固定2—3声；精确同步须看听实际素材 |
| E02 | 区分同人互斥发声、双人有意重叠、同次发声跨切；另选同步、声画分离、对位或跨时空策略 | 画外声不自动是J/L-cut；情绪一致不等于声画同步；只用一套时序解释 |
| E02a | 是否配乐、何时进入退出及所用版本 | 无音乐、后期音乐、声音主导均可；不会自动生成或选购音乐 |
| E03 | 镜头/事件时序和共同时间预算 | 串行依赖算先后，并行动作不重复累加；总和正确不等于表演自然 |
| E03a | 需要时用音频节拍定位动作 | 实际音频与工具支持决定可用性，不把写在提示里当作已同步 |
| E03b | 台词原文、说话人、单次发声编号、预计/实读时间、停顿与切点 | 语速只是估计；不把同时发生的动作/运镜时长全相加。已确认台词修改需说明并确认，拆句也要保留意义 |
