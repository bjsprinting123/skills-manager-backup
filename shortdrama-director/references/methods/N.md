# N 叙事与结构（7卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| N01 | 一句话概念、主题、人物、体量与结构选择 | 经典叙事、艺术短片、商业网剧、自定义均合法；原要素清单是提示，不是必填数目 |
| N02 | 人物欲望、恐惧、关系、背景和可能的变化 | 反差、秘密和弧光按需要；人物不必人人有隐藏底牌 |
| N03 | 复杂世界的规则、边界、代价、历史、势力与地点 | 规则不必被打破；发生改变要有叙事依据，不为模板增加神器 |
| N04 | 按场列事件、信息/情绪作用与衔接 | 商业五节拍只用于所选题材；停留、氛围与关系建立也可构成作用 |
| N05 | 把场景写成可呈现的剧本，检查对白与行动 | 说明性对白不一律删除；单场不要求同时完成全部主题/弧光任务 |
| N06 | 人物目标、处境、行动策略与可见反应 | 不要求每场必须策略失败或情绪转折；保持状态可成立 |
| N07 | 按发布体量安排开场吸引力、段落进展与收尾 | 爽点、三拍、悬念是类型菜单，不固定秒数、竖屏比例或必须悬而未决 |

## v0.1.2 增补（2026-09-09）

本节为候选增补，数字均为可覆盖的设计默认值；来源为第三方作者报告或设计借鉴，未视为本地实测。


### N08 集尾钩子强度分级
- 五级：L1好奇心、L2期待感、L3紧张感、L4情感冲击、L5情感卷入。
- 设计默认：每集至少L3，首集与季中点可用L4，关键终局集可用L5；题材可覆盖。
- 类型轮换：信息断崖、选择悬置、意外闯入、局势颠覆、情感破碎；连续两集避免同型。
- 核对：强度、兑现承诺、24小时记忆度、调性一致性。

### N09 结尾与余韵
- 余韵由情感冲击、未完成感、认知重构共同形成。
- 交付前检查：是否留下不可逆代价、未回答但不再依赖解释的问题、观众可自行完成的认知转折。
- 适用例外：用户指定爽感或大团圆时，将检查项降为提示。
