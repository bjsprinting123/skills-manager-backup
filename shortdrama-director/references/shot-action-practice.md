# 接点、动作与镜头选择实践

这是根据本包C／S／P／M／E方法整理的工作参考，不要求原作者的词库或未随包目录。按任务取用，不是必须集齐的招式／镜头数量，也不是模型成功率定律。

## 一、怎样选择镜头接点

先回答“下一镜新增什么，上一镜留下什么”。然后选择与事件相符的连接方式：

| 接法 | 要写清的前后关系 | 易错点 |
|---|---|---|
| 直接切镜 | 哪个信息需要换取景，切前与切后的当前状态 | 不必编造遮挡；切镜不代表人物回到起始姿势 |
| 动作衔接 | 同一次动作切在哪个阶段，后镜从哪个阶段继续 | 拿起物体不能在后镜重拿；接触后持有／释放要一致 |
| 视线连接 | 谁先看到什么；后镜展示视线对象或接收者 | 不能让角色先回应尚未获得的信息；余光也要有可见路径 |
| 声音跨切 | 哪个声音在切点前后连续，说话人是否仍在现场 | 一次发声只说一次；画外对白不自动是内心旁白 |
| 遮挡连接 | 遮挡物如何进入、覆盖什么、从何处显露下一状态 | 光、方向和主体位置要解释；不是所有切镜都要遮满画面 |
| 形状／构图呼应 | 前后两个可见形状或位置怎样对应，各自是什么对象 | 相似形状不是同一个物体，不能误继承身份与空间 |
| 渐变或叠化 | 是否代表时间、空间或感知变化；哪些内容重叠多久 | 持续时间是设计提案，不能同时要求无重叠硬切 |
| 连续运镜揭示 | 相机路径、看向目标、遮挡和主体路线如何连通 | 这是镜内取景变化；用户要求一镜到底时不偷加硬切 |

## 二、把动作名写成可见行为

不用“精彩对打”“高手过招”代替编排。按当前场面补充必要关系：

```text
谁发起 → 面向哪个对象／目标 → 从哪个位置、以哪只手或道具行动
→ 对方接触、避让、格挡或继续原动作 → 可见的位移／道具状态结果
→ 双方接下来各处于什么状态。
```

可选动作词按可见作用组织，不强迫使用专业招式名：接近／退开／绕行；伸手／收手／持续握持／放下；挡住／避开／失去接触；停住／转向／失衡后恢复支撑。选择符合剧情和角色能力的表达，不自动增加伤势、武器或胜负。

角色“技法偏好”可以表现为常用距离、动作幅度、出手节奏和对空间的利用，不能靠复制一串武术名保证真实。需要专业技法复现时，标明仍需专业或实际素材校核。

同一时刻可有双方并行动作，但要解释各自能看到什么、身体在做什么。动作完成后不是一律复位：持续压制、握持、停顿、主动退开都可能成立。已有伤势、疲劳和武器状态若影响后续，作为项目状态保留；没有则不为模板补造。

## 三、镜头选择依据

| 要让观众读懂什么 | 可考虑的取景方式 | 必查关系 |
|---|---|---|
| 双方距离、路线和场面局势 | 容纳双方和必要场景锚点的关系镜 | 谁在前后、路能否通过、双方是否都可见 |
| 关键接触或持物 | 让手、接触点和必要身体支撑同时可读的局部镜 | 不切掉决定动作含义的那只手／道具；接触前后状态相接 |
| 作用后的反应 | 人物或物体结果镜 | 原因已经发生且可理解，不单靠摇镜／特效冒充作用 |
| 主体持续移动 | 跟随或允许其在画内移动的机位 | 摄影机与主体分别描述，背景不无故滑动重排 |
| 原因揭示或视线发现 | 角色看向目标后切对象，或用镜内运动揭示 | 人物获取信息和观众看到信息的顺序分清 |
| 停顿与态势变化 | 保留空间关系的停留镜 | 静止可以有叙事作用，不强制每拍升级或换镜 |

侧面、正面、斜侧、俯视或环绕都是选择，不设普遍禁令。判断当前事件是否清楚，再定景别和运动；如果用户点名技巧，保留目标效果，冲突时说明替代方案。

## 四、移动人物的互动检查

对骑乘、行走、追逐中的互动，检查触发、接收、回应、结束四个关键时刻的相对位置。可以用简图、位置文字或实际素材，不强制精确坐标。

若采用具体距离和速度，就核对时间内是否已走过互动对象；不能同时说持续前进、对象一直在前方、长时间凝视，却没有空间依据。距离／速度未知时标为待定，避免虚假的几何精确保证。景别切换不会重置世界位置。

## 五、静图与视频分别使用

生图只挑一个明确时刻：接触前、正在接触或作用后，写该时刻的手位、支撑、视线、裁切和道具。单张图不承担完整攻防时序。

视频再组织变化和时间，声音对应实际事件，串行与并行分别判断。需要补图时先定义补图目的；图片正确仍不能替代动态、口型或声音验收。
