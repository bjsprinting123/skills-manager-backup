# 轻量项目记录

适用：多镜创作、资产交接或结果修订。单图单次不强制落盘建表。

## 三项记录

| 记录 | 最少信息 |
|---|---|
| 已确认设定 | 用户想表达什么；角色和关系；媒介／时代；原台词；不能添加／改变的事实；待定提案 |
| 已接受资产 | 实际文件及版本；谁接受；用于身份／造型／场景／姿态／帧锚／声音的哪一项；继承与排除；未核问题 |
| 镜头状态 | 镜头编号；生成单元；起始可见状态；事件与发声编号；结束位置／持物／接触；接下一镜的点；实际结果是否接受 |

使用用户接受的版本，不按文件名数字选最新版。计划资产与真实文件分开；同图可多职但每项职责要相容。

每个发声事件有一个身份，跨切只是同一事件的延续，不复制整句。持续动作、已经完成的动作、主动改变和跳时分别记录；镜头切换不意味着人物自动归位。

世界中的左右、人物身体左右和当前画面左右分开。改变机位后按世界锚点重算画面投影，不要求画面像素位置始终不变。

## 可用交接格式

按需填写，不必每次生成所有表格。

```text
项目／当前阶段：
已确认／不可改：
暂定方案：
实际接受资产及用途：
本镜起点 → 关键事件 → 终点：
前后镜接点／同次发声：
本次改动／保持项／影响后续：
待用户生成或确认：
采用的Skill及知识版本：
```

写文件时沿用项目已有记录，避免多份“当前版”。原样片、原提示、改稿和接受版保留来源关系。换规则版本需说明影响；已有作品可以继续使用原版本。
