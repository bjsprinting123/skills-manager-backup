# Krea2写法与输入职责

## 自然语言画面

按本图必要信息组织：主体及身份锚点 → 一个时刻的动作／接触 → 空间与构图 → 光线和材质 → 媒介与色彩 → 必要保留／排除。次序可为视觉重点调整，不每图填满所有项目。

简短意图可扩为具体画面，已经详尽的输入优先去重、消歧和轻量整理。保留用户明确的主体、行为、数量、颜色、关系、媒介和画中文字，不为凑长度增加无关人／物／剧情。

固定字数不是官方有效性门槛。描述“看起来怎样”优先于8K、masterpiece、完美、镜头品牌的无益堆叠。画幅与实际生成尺寸可以放说明中，正文仍可表达必要的留白与裁切。

要生成的可见文字用双引号括起并保持原语言。不是所有字都要删除：衣服图案、匾额与创作者签名／截图UI需分开，只有用户需要的内容才继承。

## 图片不止一种角色

| 途径 | 可以写什么 | 需明确的边界 |
|---|---|---|
| 助手看图转文字 | 基于可见事实的目标画面描述 | 不是找到原作者提示，也不是生成器收到原图 |
| 风格参考 | 借色彩／笔触／媒介，内容另写 | 官方存在专门风格参考路径，但风格不等于锁身份 |
| 结构控制 | 姿态／深度／布局的控制目标 | 有兼容控制入口才可使用；不因此保证脸与服装 |
| 图生图／遮罩 | 保留区域、变更区域和目标状态 | 源图／遮罩须真正接入，文字“其他不变”不是像素保护机制 |
| 专门编辑扩展 | 源图＋明确修改任务＋保持项 | 需要已确认的编辑能力，不属于所有基础Krea2入口 |

RAW／Turbo、LoRA、文字编码器、参考途径和二次扩写可能改变表现；这些放能力记录，不向用户编造本机参数。官方在线API的Moodboard字段不自动适用于本地ComfyUI。

## 多图／编辑分支

逐图写职责，例如A只给衣服、B只给光色；禁止因排序不明就默默换脸。普通轻微缺项可以标提案，互斥身份或关键布局必须先确认。一个文件可承担多项相容职责。

只改变用户指定部分。镜头角度变化可能揭示参考图没显示的背面，标为设计补充而非已观察事实。没有编辑入口时提供“文字重建目标”或建议支持的替代，不声称精准只改局部。

## 静图给视频使用

分清角色板、站位图、单张开场和末帧。给角色板的多栏布局不进入普通电影首帧。关键帧需写当前已经完成／尚未开始的动作；它负责一个时刻，不包含“先笑再点头再转回”的完整时间序列。

手／脚、头饰／鞋底、人物和坐骑等该镜需要的部位不得被无意裁掉。强虚化适合部分人像，不自动适用于需要读清关系的多人首帧。
