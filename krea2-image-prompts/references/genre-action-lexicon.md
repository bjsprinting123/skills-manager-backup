# 题材、徒手与兵器：影视动作词库

用途：人物动作风格、打斗分镜、动作参考图、复杂镜头补图。普通肖像、日常文戏不需要加载本专题。目录：A 使用边界；B 24类徒手/身法；C 六类专项；D 题材与场景；E 静图、视频与复核。

本文件是独立改写的**影视化动作设计参考，不是真实武术教学**。流派名称保留作检索；下述可见特征是创作取样，不是完整流派定义。未经过武术、特技或历史专家校核，不将原资料中的“正统”“全体系”、传承故事、游戏技能数值当成已核实事实。现实拍摄的接触、摔落、兵器、攀爬须由合格专业团队另行设计。本 Skill 只写画面与叙事，不指导造成伤害。

## A. 使用边界与选择方法

先问本场人物要完成什么：逃离、护人、拖延、夺回物件、切磋、制止冲突，还是决胜。动作服务这个目标；可以停手、退让、认输或被打断，不强制摔后追击、终结、情绪逆转或混合多个流派。

输出可见关系：**谁在何处 → 做什么动作 → 对方如何回应 → 双方新位置与物件状态**。风格名称用于检索，不代替正文。选择几个能形成辨识度的动作即可，没有固定招数、秒数、镜头数、流派配额或成功率保证。

分类使用三个层级：

- **写实外观**：人物重量、支点、惯性、持握和环境反馈保持可信；不等于经验证的实战技术。
- **影视夸张**：夸大跨度、节奏、停顿、翻转等，需要表演、剪辑或特效辅助；不称为普通人可执行。
- **幻想机制**：踏云、踩光、时间冻结、御剑、能量化物等。说明机制、发生范围和结束状态，不能因写了“借力”就当成现实物理。

给模型写正文时优先明确动作关系，不用掌门、传承、伤害倍率等名目代替可见描述。原作人物、专属服装、武器名、招式名称及固定配色均不自动绑定给原创人物。用户明确指定某个 IP 时仍需另核设定与素材使用条件。

## B. 24类徒手与身法风格卡

各例都是分镜描述片段；应按实际人物、机位、时长改写。采用近景时只写能被看见的细节；要检查脚步、落地或翻转就保留相应身体与地面。

### B01 八极拳：紧凑靠近、短促停收

- 可见特征：身体整体随进步靠近，拳、前臂或肩的短动作与躯干同步，动作结束有明显回收。用一次沉步和衣料绷紧表现重量，不依赖震碎地面。
- 示例：“灰衣人进到近身距离，短促的肩部前送迫使对手退步；他站稳便收住，双手恢复戒备。”
- 适用/限制：适合护门、护人或力量型人物；不等同每招都跺脚，也不自动获得隔空冲击波。
- 检查：肩与身体一起移动没有断开；对手反应发生在接近之后；脚不滑行穿地，收住之后不重复撞击。

### B02 形意拳：进步与直线动作同拍

- 可见特征：行进方向清楚，躯干随脚步前移；直线短动作与高低姿态变化形成节奏。劈、钻、崩、炮、横只作原资料的检索标签，正文写实际方向。
- 示例：“人物沿走廊向前进步，前臂由高处落到胸前，随后短拳前送；对手退到门柱旁，两人同时停住。”
- 适用/限制：适合推进、逼退、急于结束冲突的角色；不是只有直线，也不把每步固定成某一招。
- 检查：拳与步是否同一进程；前后关系是否被切镜反转；姿态改变后是否还能接下一动作。

### B03 咏春拳：短桥与中线接触

- 可见特征：近身、前臂动作紧凑；摊、伏、膀、拍等标签可转写为前臂外移、下落、偏转、短暂接触与收回。避免一团高速手影。
- 示例：“门口两人的前臂短暂相接，女子把来臂向外带开一点，另一手从胸前前送后立即收回；镜头保留双方肩线与两只手。”
- 适用/限制：适合狭小空间和细密对招；角色若需移动仍可移动，不把‘守中’误成双脚永久固定。
- 检查：左右手归属可追踪；接触关系没有凭空跳换；短拳不能在尚隔几步时击中。

### B04 太极拳：连续弧线与迟早变化

- 可见特征：手臂绕弧、身体转向、来势从身边经过，随后双方距离改变。掤捋挤按采挒肘靠是检索名称，不要求一镜全用。
- 示例：“老者随对方前进转身，双手顺着接触处画小弧，对方继续跨出一步；老者把手收回，没有追加动作。”
- 适用/限制：适合克制、防反、切磋；不默认为永远慢动作、站桩或不接触就让对手飞走。
- 检查：引导前是否已有接近/接触；双方脚步是否支撑转向；移动结束没有无来源的弹飞。

### B05 醉拳：失衡假象与突然稳住

- 可见特征：身体摇摆、步幅忽短忽长、似跌而未跌；突然稳住或转向构成反差。
- 示例：“青年踉跄挪到桌边，身体向后倾得像要跌倒；他扶桌稳住，借这个停顿绕到空出的出口。”
- 适用/限制：喜剧、武侠、误导对手；不要求真喝酒，不把失衡直接解释成超能力。
- 检查：支撑手确实碰到桌边；桌子没突然移位；摇摆和重获平衡有过渡，不是骨骼任意折叠。

### B06 螳螂拳：勾状手形与短暂牵连

- 可见特征：手形变化、短距离接触、迅速分开和再接近；让观众看懂“抓到还是没抓到”。
- 示例：“黑衣人的手由张开变成勾状，轻短带动对手袖口；对手退开，袖料绷紧后松下，双方恢复距离。”
- 适用/限制：适合敏捷、短促交锋；不将手指形态当作伤害秘诀，也不强制攻击面部要害。
- 检查：手指没有增生；袖口拉伸与人物移动同步；松手后不继续远程牵引。

### B07 散打：踢、打、摔之间的距离变化

- 可见特征：远处试距、接近后的拳臂动作、贴身转为身体位移；转换前应看见距离已经改变。
- 示例：“两人在垫面试探，青年退半步避开踢腿；对手收腿后靠近，两人短暂拉扯，随后分开。”
- 适用/限制：现代训练、比赛或写实外观的冲突；比赛规则和合法动作须另核，不能把任意肘膝写成散打规则。
- 检查：踢腿是否收回再换脚；贴身过程是否存在；摔倒方向和接触位置连贯。

### B08 泰拳：护架、距离与厚重回应

- 可见特征：护架、站位调整、躯干转动、腿部弧线；近身时肘膝与远距离腿法的视觉范围不同。
- 示例：“练习者保持高护架，踢向训练靶后回到站姿，持靶者受力退小步；呼吸声重新清晰起来。”
- 适用/限制：训练、竞技气质、近身压迫；不自动加入箍颈伤害细节，具体赛制另核。
- 检查：靶的位置与动作匹配；支撑脚和身体转动一致；没有隔空击中或持续失控旋转。

### B09 擒拿：控制关系与放开

- 可见特征：谁抓住哪只手/衣袖、双方朝向如何改变、何时解除接触。避免关节极限角度和伤害操作。
- 示例：“女子抓住青年右袖，阻止他继续上前；青年停步回头，她看到他冷静下来才放手。”
- 适用/限制：制止、护人、擒获的剧情表达；不必发展为骨折、追击或倒地，具体招名不是动作正确性的保证。
- 检查：控制手未在切镜后换边；衣物/手腕关系连续；放开后姿态与压力解除同步。

### B10 柔术：地面位置与角色意图

- 可见特征：谁在上/侧/后，接触肢体如何遮挡，人物是否尝试移动或示意停止；位置比招名更重要。
- 示例：“垫面上两人侧身相对，一人抬手示意暂停，另一人立刻松开并向后坐起；镜头保持双方面孔可辨。”
- 适用/限制：训练、困境、受制状态；本词库不教绞勒、关节降服，不把‘柔术’默认为单一学校全部规则。
- 检查：四肢归属、上下位置与遮挡可理解；暂停后真正解除；不以表情代替未呈现的位置变化。

### B11 跆拳道：伸展腿线与落地回收

- 可见特征：腿部舒展、身体转向、短暂停留后的落脚；旋踢与后空翻不是同一运动轴。
- 示例：“少年在空旷训练场完成一次转身踢靶，落地后稍作调整，重新面向教练。”
- 适用/限制：训练、青春、展示型动作；不强制高位踢、540度或一镜复杂连踢，竞技规则另核。
- 检查：起跳与落脚数量一致；旋转轴未变成翻滚；靶未穿过腿，落地后还能稳定接戏。

### B12 空手道：明确起止与轮廓

- 可见特征：拳掌方向清楚、展开与回收可辨、动作之间有有意的节拍。
- 示例：“白衣练习者在场中央完成一次直拳展示，动作停稳后将手收回，目光仍对准前方。”
- 适用/限制：仪式、训练、干脆的对峙；不把‘寸止’误成视频必须冻结，也不宣称一击必胜。
- 检查：终止是人物主动收住还是视频卡帧；手臂没有瞬间伸长；衣袖动态和身体停收一致。

### B13 蔡李佛：较宽弧线与左右衔接

- 可见特征：较舒展的臂线、左右动作轮换、身体随之转向；需要留出手臂运动范围。
- 示例：“人物在院中向侧方展开手臂，再随转身换到另一侧，衣摆沿转向稍晚落下。”
- 适用/限制：宽敞庭院、群体关系明确的交锋；不把每次摆臂都写成旋风或与蔡拳混为一个标签。
- 检查：手臂弧线不穿墙或路人；左右轮换后朝向正确；环境反馈不是提前发生。

### B14 洪拳：稳健下盘与前臂开合

- 可见特征：下盘稳定、手臂开合幅度明确；沉、分、架、推等桥手意象可以转写成空间关系。
- 示例：“守门人沉住身位，前臂从胸前分开拦住门口；看清来人后，他松开架势让出通道。”
- 适用/限制：守点、稳重人物、武馆；不强制每镜深马步、硬碰硬或地面裂纹。
- 检查：重心与脚底接触一致；站稳不是完全僵住；前臂张开确实改变通道宽度。

### B15 蔡拳：侧向入口与快进快退

- 可见特征：小范围斜向换位、躲开正面线路、接近后迅速离开；与较宽弧线的蔡李佛作创作区分。
- 示例：“人物从对手侧面闪到桌边，短暂接触后退到灯下；镜头让两人和桌角始终保持同一关系。”
- 适用/限制：灵巧人物、局促空间中的换位；‘三角步’只是路线提示，不背书某一传承的唯一规范。
- 检查：换位有经过的路径；旁侧确实留有空位；角色没有穿过桌角或直接瞬移到身后。

### B16 合气道：转向引导与整体移动

- 可见特征：双方接近后沿弧线转向、一方身体随另一方移动；重在前后状态，而非小关节技巧。
- 示例：“一人抬手示意，同伴随接触转过身，沿弧线跨出两步；两人面向同侧后主动分开。”
- 适用/限制：克制、切磋或‘改变方向而非硬碰’的表演；不把无接触摔飞视为现实效果。
- 检查：转向原因可见；没有以不合理关节角度代替身位移动；不把一次转体拍成永久转圈。

### B17 八卦掌：围绕关系而走

- 可见特征：相对对手的弧线走位、身体朝向持续调整、手部动作跟随空间换位。
- 示例：“女子绕着场中的对手向侧面行进，掌势随转身变化；两人最终停在石桌两侧，彼此仍能看见。”
- 适用/限制：周旋、绕侧、观察对手；不是所有动作都必须走整圆，不强制环绕摄影机。
- 检查：人绕对手还是摄像机绕人要分清；脚步弧线与相对位置一致；中途遮挡后身份未互换。

### B18 截拳道：动作未完成时的打断

- 可见特征：一方正要前进，另一方较短的动作使其停住或改变计划；重点是先后关系。
- 示例：“对手刚抬手向前，青年便抬臂挡住入口；对手收住，青年也不追击，双方重新审视。”
- 适用/限制：敏捷、判断快、节奏改变；不把‘零前摇’写成没有任何身体运动的瞬间命中。
- 检查：打断发生在对方动作过程中而非结束之后；双方反应符合因果；不靠瞬移缩短距离。

### B19 巴西战舞（Capoeira）：摆动、翻转与空间游戏

- 可见特征：身体有弹性摆动，侧手翻或低姿态转换与对手距离呼应；先写身体运动，再选音乐。
- 示例：“两人在圆形空地相对摆动，一人侧手翻换到另一侧，同伴让开路线；落地后恢复相对姿态。”
- 适用/限制：舞蹈式交锋、开放空间、表演；原资料音译招名未作专业核对，正文不用音译代替动作，也不将有手撑地称为无支撑空翻。
- 检查：撑地手和着地脚清楚；翻转有足够空间；不是一边同速绕圈一边不看对手。

### B20 柔道：站立到落地的关系变化

- 可见特征：服装接触、双方重心关系、整体翻转或落地后的间距；镜头保留起点、落点。
- 示例：“垫面上的练习过渡到一方侧身落地，另一方仍扶着其袖口；落地者示意无碍，双方放开起身。”
- 适用/限制：训练、竞技或剧情摔落；源‘67式’目录有重复与分类疑点，本包不作为完整官方技目，不提供摔人操作步骤。
- 检查：不能从未接触直接变成过肩；落地方向和衣袖关系连续；摔后允许结束，不强制追击。

### B21 武侠身法：现实移动与幻想错位分开

- 可见特征：折线、侧移、遮挡后再出现、绕行、换高低；每段写起点、路径、落点。
- 示例：“侠客借门柱遮挡绕向回廊，重新出现时已在柱子另一侧；对手转头才发现他。”
- 适用/限制：武侠、潜行、追逐；源含凌波微步等小说名，本包转为普通可见路径；空中反升、踏水必须标作幻想或特技表达。
- 检查：遮挡前后可用空间相容；残影不是新人物；真正瞬移需用户设定，不能用‘高手’替代原因。

### B22 谭腿：弹收清楚、上身配合

- 可见特征：腿部屈伸较清楚、回收迅速，上身保持平衡。源以弹、踩、截、蹬、劈、挂、撩、扫、鞭、踹、膝、摆概括12类，作为创作词而非正统套路谱。
- 示例：“练习者向训练靶做短促弹腿，脚回到身下后才向前走；教练抬靶示意下一轮。”
- 适用/限制：训练、腿法突出的人物；不照搬拳腿比例、起源传说、固定12路流程或目标伤害。
- 检查：每次出腿都有回收/落脚；上身没有漂移；镜头含脚时动作不能被衣服全部遮掉。

### B23 36路腿法（三十六路腿法）：按轨迹检索

- 可见特征：用直线伸展、内外弧摆、转身、腾空、低扫区分画面；组合先拆为单段再说明衔接。
- 示例：“青年先做一次低位扫过的展示，收腿站稳，再抬腿画出较高弧线；两段高度差在同一全身画面中可见。”
- 适用/限制：动作选择与编排词库；36路是源目录命名，不保证每一项都是经核实的标准拳谱，也不把进阶目录强塞进短镜头。
- 检查：运动轴、支撑脚、高度变化和中间回收是否成立；两个动作不能合成一条反折的腿。

### B24 少林旋风地堂腿（地趟低腿）：低位动作与地面支点

- 可见特征：低姿态、侧滚、手掌撑地、身体由低到高恢复；区别于从站立直接起跳。
- 示例：“人物侧滚到空处，一手撑地抬起上身，低姿态转向后恢复站立；对手保持在另一侧。”
- 适用/限制：武侠的脱离、翻身、低位展示；复杂连环腾空属影视夸张，门派正统性未核，不给锁膝伤害动作。
- 检查：手确实触地再支撑；滚动轴连续；从卧姿到站立不是瞬间换模型，身体不穿地。

## C. 六类专项：兵器、轻功与幻想动作

### C6 修仙高级剑招：25个源索引的幻想结构

关系：先定义剑是手持、御剑飞行、能量化剑还是阵中实体剑；哪把用于飞行、哪把握在手里必须分开。能量剑阵可以多道，但人物原本持有的剑不因光效倍增。未指定色彩、阵型或分身时，只补满足本场表达的内容。

| 源索引 | 原创、可见的幻想表达 | 失效检查 |
|---|---|---|
| 天罡横旋 | 人物随剑路向前转进，环形剑光逐段留下。 | 单一人物与实体剑仍可辨；旋转方向连续。 |
| 九霄凌云 | 足下剑光托举人物分段上升，在高处停住观察。 | 托举机制、剑是载具还是手中道具明确。 |
| 逆鳞翻江 | 身体向后翻转，剑光沿反向弧线经过，落地收住。 | 翻转轴、落点与持剑手一致。 |
| 星河倒卷 | 细光从外围卷向中心，再沿新方向舒展开。 | 收与放先后不同，不是一团无结构爆炸。 |
| 流云追月 | 人物在明确的几个落点之间移动，每次稳定后剑路接续。 | 真身位置、阶段次序可追踪。 |
| 惊鸿三叠 | 正前、侧方、较高处依次换位，每段对应一次清楚动作。 | 三段为源意象，是否三段依用户；不可同时存在三个人。 |
| 莲华绽放 | 光轨由人物周围向外形成瓣状，再回收成护身边界。 | 向外与向内分时发生；人物仍在中心。 |
| 龙渊潜行 | 人物低位移动，剑光沿地面延伸，接近目的地时向上收起。 | 地面路径不断裂，剑尖不穿地板。 |
| 凤舞九天 | 人物借连续可见剑光托举改变高空路线，最后下降。 | 允许幻想但交代路径；不强制九次换向塞入短镜。 |
| 万剑归宗 | 多道能量剑形由四周聚集，最终收成一束前行光线。 | 聚集与发出有次序；实体剑和能量剑区分。 |
| 阴阳轮转 | 两种光轨沿相反方向轮换，随人物动作改变护持侧。 | 两轨不自动变成两把实体剑；颜色由项目确定。 |
| 断浪新潮 | 剑光像波层先后向前展开，前层变淡后后层接上。 | 递进有空间与时间差，不用同时爆闪替代。 |
| 百步穿杨 | 先交代远处目标物，再让一条细剑光沿清楚方向抵达。 | 远目标不能仅以剑尖特写替代；不保证精准命中能力。 |
| 缥缈幻影 | 真身连续换位，旧位置留短暂淡影并消散。 | 淡影不各自独立出招；真身最后位置明确。 |
| 天外飞仙 | 人物与剑光同向长距离下降，在平台前减速停住。 | 起点高度、接近方向、最终位置清楚。 |
| 陨星坠地 | 高处剑光收亮后下落，地面到达点向外出现环形余波。 | 先到达后余波；爆光不抹掉角色落点。 |
| 盘龙缠身 | 龙形光轨绕目标道具外侧形成限制边界，随后松开。 | 光是能量，不是实体长剑弯成绳子。 |
| 回风拂柳 | 外圈剑光带开来势，内侧短光随人物转向收回。 | 来势在先、转向在后，不能只见反击结果。 |
| 雪落无痕 | 雪片状微光从高处依次落向空地若干点。 | 落点可见、有先后；不默认人体要害或暗杀。 |
| 乾坤一掷 | 手中长剑离手沿明确路线飞出，转弯后回到原手。 | 离手时原手为空；回路与接回时刻完整。 |
| 剑气长城 | 光墙逐层在人物前方升起，受到来光影响后稳定下来。 | 人物、被保护者、墙、来势的前后顺序。 |
| 踏雪无痕 | 人物沿雪地绕到场景另一侧，剑保持在身侧。 | 无脚印属风格/幻想选择；绕行不能靠无原因瞬移。 |
| 九转轮回 | 人物沿剑阵边缘逐次换位，阵心始终作为空间参照。 | 阵型、人物路径和镜头运动不能同时无法追踪。 |
| 破空裂虚 | 剑划过后留下狭长空间裂痕，裂痕随后缓慢合拢。 | 起源、延展、结束明确；不自动附带范围伤害。 |
| 大道无形 | 人物只有很小的抬剑动作，对面灯焰随之偏转，双方停住。 | 以可见反应支持克制表达，不写“什么也看不到但威力无限”。 |

静图：选剑阵形成中或形成后的一种状态，写清前中后层、能量剑与实体剑、人物站位。视频：描述聚集、发出、碰撞/停住、消散中的实际需要部分；同一镜的宏观阵型和微小表情不可都承诺极清楚。复杂结果不满意，优先补阵型/持握/关键时刻图，再重写动态。

## E. 从词库到交付：图片与视频分开

**静图用途**：人物辨识、服装全身、道具全形、持握关系、站位、环境结构、关键时刻。按本镜头缺什么选什么，不规定每次必须生成全套。俯视图是规划工具，只有用户的实际工作流支持并正确绑定时才是模型输入。

静图正文示例：“原创成年女剑客，灰色短外套，右手握一把直身长剑的剑柄，剑尖朝画面右下，左手放松；站在庭院石阶下，身体全长与整把剑完整入画，剑鞘在左腰。此刻尚未出招，背景留出两侧空间。”这里描述的是一个时刻，不包含“随后转身、再收剑”。

**视频用途**：按已确认的参考职责分别继承身份、服装或具体帧状态，不把普通身份图的姿态自动当成首帧。除非用户明确要求回放／倒叙，不无说明地重演同一次已完成动作，并写清最后状态。未提供或未确认引用时可先交不带虚构编号的文字方案，待绑定项放在模型正文外；素材不足时不声称已经是可直接执行的参考稿。本文件不是某一模型的格式说明。

视频正文示例：“两名原创成年练习者在空庭相对而立。右侧人物向前一步抬起木剑；左侧人物退向侧方，两剑短暂相接后分开。双方站稳，放低木剑，相视示意结束。固定中全景保留两人、完整道具和落脚处。木剑碰触一声，之后只剩衣料与呼吸，无自动报招。”具体时间、语言与引用交给对应模型适配，不能把这一段当作全部模式通用结构。

复核时逐段观察：

1. 身份、衣服、实体道具数量及持握是否与已接受资产相同。
2. 起点、运动路径、支点、落点是否连续；需要真实运动依据的地方是否只是幻想词掩盖。
3. 两人是否真正接近或接触才出现反馈；手、腿、剑、绳索有没有穿插或归属不明。
4. 缠斗、摔落、变形、归鞘有没有结束状态；下一镜是否从这个状态继续，而非重演。
5. 特效依附什么、何时发生、何时消失；残影有没有变成新人物/新武器。
6. 景别是否足以看清本镜目标；大全景无法核验细指、特写无法核验落地路线时，标未看清而非合格。
7. 图片错在持握/结构就补对应图；视频错在动作密度/衔接就先调整动态。未看听完整视频，不宣称动作或声音验证通过。
