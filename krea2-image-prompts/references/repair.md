# 根据实际问题修订

先记录具体输入、实际文件和问题时段／区域；分别写观察与原因假设。拿不到视频或音轨时，不用截图／字幕假装已完成动态或声音检查。

| 现象 | 优先排查 | 可采取的措施 |
|---|---|---|
| 错脸／服装漂移 | 接入的资产与接受版本、参考职责、文本与图冲突 | 纠正引用；补身份／造型图；有支持的编辑路径才提出局部编辑 |
| 坐姿／骑乘／持物融合 | 接触面、手部占用、尺寸、遮挡与起点 | 共同构图／关键姿态补图，或重设计可读机位 |
| 开场站位错 | 场景锚点、图被当风格还是首帧、裁切 | 补开场构图图／布局说明，核实际输入用途 |
| 中段动作断裂 | 串并行依赖、运动路径、时间容量、末态冲突 | 改动态／拆段／补必要中间状态；静图正确不保证运动正确 |
| 表演过满／提前反应 | 注意目标、触发时刻、原有情绪与新增反应 | 保留原情绪，减少互斥动作，重新安排回应；不强制所有情绪升级 |
| 台词／音效出错 | 原话、说话人、单次发声、重复引用、实际音轨 | 改声音时序或输入角色；声音问题不一律补图 |
| 运镜／技巧未实现 | 指定效果、路径、遮挡、取景与能力 | 说明限制并提出替代；未经允许不偷换技巧 |

## 补图闭环

定位问题 → 指定补图目的和一个时刻 → 用户生成／提供 → 检查实际图 → 用户接受版本 → 重写完整受影响提示 → 检查前后镜 → 用户再生成／判断。

补图单写：保留项、改变项、用途、起始姿态／手位／接触、必要可见部位和验收目标。旧冲突图不与新图同时充当权威。布局图主要供设计，不自动送成视频首帧。

一次改动优先针对可定位问题，必要时允许有说明地重新设计。反复没有改善时换路线，不无限加长提示词或追加泛用禁令。改剧情、台词或重要技巧需确认。

## v0.1.2 诊断修复

先区分已批准意图、实际输入和实际观测输出；转述而未亲看的结果标为待确认，文本校验通过不等于媒体绑定生效。失败归类为规划、序列化、渲染、参考权威、运行环境或模型行为，修最小责任方。受控重试只改一个变量并记录保留项；多处联动改动须明确标为重写。
