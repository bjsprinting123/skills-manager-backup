# M 动作与打斗（7卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| M01 | 动作目的、关键作用与可见后果 | 写实先查身体/空间可行性，幻想按世界规则自洽；不以“真人做不出”一票否决幻想 |
| M02 | 持物、手位、身体占用及关键动作的起终状态 | 同一主要动作不能无说明重播；移动中的动作可以经过多个位置，不误解为只能发生在一点 |
| M03 | 目标、阻力与动作后局面变化 | 招式多不等于场面清楚；专业步法/重心/兵器距离仍缺验证 |
| M04 | 一攻一应：发起者、目标、接触/格挡/落空、回应、位置变化和后续；按需展开预兆→加速→接触点→材质变化→受力方向→位移结果→余波 | 保留结构语法，不接受“完播率乘法公式”、固定触碰秒点、必反转等为实证规律 |
| M05 | 角色技法偏好、距离、动作变化及招式/终结使用记录 | 把技法转为可见行动，需要展开时读取本包[题材动作词库](../genre-action-lexicon.md)。技法数量、比例和零重复不是硬门槛 |
| M06 | 景别、角度、机位、跟随目标和动作可读性 | 不普遍禁侧拍或环绕；按[实践说明](../shot-action-practice.md)选镜，玄幻／风格化需求再读[八类画面模式](../action-camera-8.md)，不能以镜头名替代几何与切点判断 |
| M07 | 特效绑定身体部位/轨迹/环境后果；记录结果和改法 | 冷暖对抗、拖尾等按美术选择。发布数据仅用户自愿提供，相关性不冒充因果，不默认发布 |
