# 八类打斗画面模式：构图、运动与特效协作

用于用户已选择玄幻、异能、动画或风格化打斗，并希望设计关键画面、动作段落或特效关系时。普通人物资产、生活文戏和无打斗的少年游街，不需要调用本专题。

来源对应：`seedance-combat-prompt`《打戏系统交接包》6.4 所称“精品镜头8种黄金模式”，以及其 `SKILL.md` 的模式 A–H。这里的“黄金”是来源命名，不是行业标准、效果保证或传统摄影的八种基本机位；其中多项实际上是特效构图和动作表现模式。本篇以自有文字重述核心思路，补充静图／视频转换、检查和限制；无需下载原仓库、角色资产或私人提示词即可使用。

## 选用与交付

先确定这一画面要让观众读懂什么，再选模式；一段打斗不需要凑齐八项。角色、胜负、能力、特效颜色和环境损坏沿用已经确认的设定。尚无此类设定时，提出可选方案，不把示例颜色、元素或破坏程度当成角色事实。

| 观众要读懂的信息 | 模式 |
|---|---|
| 力量尚未释放，但威胁正在增加 | A 低仰蓄力 |
| 攻击从哪里经过、朝哪里运动 | B 轨迹拖尾 |
| 两股力量在哪里接触，防御如何变化 | C 接触点双色咬合穿透 |
| 接触造成多大范围的空间后果 | D 全景冲击波 |
| 此刻一方明显压住另一方 | E 不对称特效压迫 |
| 谁使谁失去平衡，身体怎样翻转落下 | F 翻摔全肢展开 |
| 两方暂时势均力敌，结果仍未揭晓 | G 元素对称对峙 |
| 谁控制了战后空间，能力留下什么痕迹 | H 角色签名地面 |

写成可见事实：人物及位置 → 一个明确动作阶段 → 相机看哪里／如何运动 → 特效从哪里产生、何时发生、如何消退 → 段末状态。模式名称是设计标签，不能代替正文。相机角度、占画面比例和特效长度按目标画幅、动作可读性、风格及实际结果决定；自然语言描述不保证模型精确执行几何值。

静图选择一个时间点；视频才描述状态变化。关键帧应注明是接触前、接触中还是接触后，避免首帧已经完成命中却要求模型再演一遍同次命中。声音如需要，应另写发生时机和声源，不用声音掩盖画面因果缺失。

## A 低仰蓄力

- **适用目的**：表现攻击前的准备、体量和威胁，或强调一个重要决定。适合已有铺垫的蓄势，不必把每次普通出手都放大成终结技。
- **主体／相机／特效关系**：主体的支撑、身体收束和注意方向可读；相机位于较低位置，仰视主体，可稳定观察或缓慢接近。若能力设定允许，特效向手、武器或身体附近的确定位置汇聚，而不是同时向各处爆开。对手是否同框取决于是否需要交代距离和力量差。
- **写法示例**：青衣角色站在断桥近端，双脚保持支撑，持杖的手缓缓收向胸前。相机从略低的位置看见他的上身与杖端，缓慢靠近；先前散开的青色光屑向杖端聚集，对岸人物仍在背景中，尚未发出攻击。
- **静图／视频**：静图选蓄势已清楚、释放尚未发生的姿态，交代光团位置和大小；视频说明由松到紧、汇聚到停顿的变化。用户要迅速出手时缩短或省去蓄势，不强加长前摇。
- **验收点**：人物脚底和重心可信；蓄力位置没有漂移；主体未被光效吞没；首末状态确实尚未释放；如有对手，其空间关系连续。
- **局限**：仰视不必然等于强大，近距离透视也可能造成滑稽或畸变。来源的固定角度、主体占比、暗天背景和实体能量形状均不作为必选条件；写实打斗可只保留身体准备和构图。

## B 轨迹拖尾

- **适用目的**：帮助看清挥动、腾空或弧线攻击的方向与范围，形成风格化速度感。重点是动作路径，而非把效果画得越长越好。
- **主体／相机／特效关系**：先确定真实肢体或武器的位置，再让拖尾沿其已经经过的路径留在后方；相机可侧向观察、跟随主体或适度跟随动作末端。选择能同时辨认身体和轨迹的距离，保留运动目的地。
- **写法示例**：持剑角色在画面左侧完成一次由左上向右下的斜挥，剑身清晰，淡金色弧光留在剑刃经过的路径后方，弧光末端逐渐变淡。相机保持能看清持剑手和上身的侧向视角，动作结束时剑停在右下方。
- **静图／视频**：静图表现挥动中的单一姿态与残留轨迹，不把多个完整肢体当作默认残影；视频写清起点、经过、终点及拖尾消退，避免轨迹突然在身体前方凭空出现。
- **验收点**：拖尾属于正确武器／肢体；没有被模型解释成额外手臂或多把剑；轨迹方向与动作相符；末端停下后余迹按设定消散；对手和接触点仍可辨认。
- **局限**：夸张拖尾可能遮挡动作、改变武器长度或让快速动作显得缓慢。写实题材可改用少量运动模糊、衣摆和环境反应，也可完全不用；不设“至少身高若干倍”或“越长越强”的门槛。

## C 接触点双色咬合穿透

- **适用目的**：突出一次关键接触以及防御由维持到出现缺口的变化。名称中的“穿透”指来源的能量层关系，不自动意味着身体受穿刺或需要血腥画面。
- **主体／相机／特效关系**：明确进攻物、防御物和它们之间的接触面；相机靠近但保留必要的手、武器或护罩边缘，以便知道力量各属于谁。两种可区分的特效在接触处相互挤压，随后按已定结果凹陷、偏转、破开或分离。
- **写法示例**：近景中，左侧角色的金色杖端抵住右侧角色的蓝色护盾。接触处先形成小范围亮点，护盾表面向内凹，裂隙仅从该点向外展开；杖端保持可见，随后护盾局部碎散，画面不展示身体穿刺。
- **静图／视频**：静图只选首次相触、变形或破开中的一个阶段；视频按接近→接触→防御变化→结果组织。若剧情是格挡成功，则写偏转和分离，不借模式擅改成破防。
- **验收点**：特效归属不交换；变化从实际接触位置发生；武器没有无因穿模；可读出防御成败；镜头结束仍能接回整体空间。
- **局限**：两色区分是可选视觉策略，可用亮度、形状、材质区分同色力量。过近特写容易失去攻防关系；可先交代双方再切近，或保留同框中景，不规定特写必须停留某个固定时长。

## D 全景冲击波

- **适用目的**：把重要接触的影响扩展到环境，交代作用范围、力量方向和后果。适合确有范围冲击的能力，不给普通推搡自动添加地裂。
- **主体／相机／特效关系**：全景或其他足够宽的构图包含接触点和有意义的环境尺度；冲击从明确源点向外传播，环境按距离、材质和既定能力产生反馈。相机可以稳定观察，或有目的地拉开以揭示范围。
- **写法示例**：两股力量在庭院中央相接，相机保持宽景，让中央接触点和两侧石阶同框。尘环从接触处向外贴地扩散，先掀起近处落叶，再抵达较远石阶；双方人物始终留在原有两侧，石阶主体保持完整。
- **静图／视频**：静图选冲击扩散到某一范围的时刻，环形、尘土或碎屑只是当下状态；视频交代接触先发生、扩散随后到达环境，再确认人物落点和场景变化。
- **验收点**：冲击圆心／方向与源点一致；环境反应有时间先后；人物未随特效凭空换位；损坏范围不超出剧情设定；下一镜继承已经产生的痕迹。
- **局限**：效果不一定为完整圆环，定向冲击可以呈扇形或单向传播；不强制裂地、爆炸、震镜或同时叠加多种破坏。宽景能显示范围，但不能单凭远处爆光证明具体命中。

## E 不对称特效压迫

- **适用目的**：让观众在某个时刻读出局部优势或被压制感。表现的是镜头选择中的力量关系，不等于自动确定最终胜负。
- **主体／相机／特效关系**：优势一方的特效、运动方向或明暗范围占据更多视觉空间；另一方仍保留可读的姿态、反应和退路。相机选择能表现这种不均衡的位置，不只把弱势人物裁掉。
- **写法示例**：左侧角色的深红气流沿地面持续向右推进，右侧角色守在石门前，周围仅留一圈狭窄的浅色护光。镜头缓慢横移保持二人同框，右侧角色后退半步重新站稳，气流没有遮住他的双脚和脸。
- **静图／视频**：静图用视觉面积、位置和人物反应表达当前压迫；视频表现优势怎样建立、另一方怎样抵抗或调整。若后续反转，保留反转发生前的状态，不提前把对手变成毫无行动能力。
- **验收点**：双方身份和特效归属清楚；被压制者仍可看见；视觉不均衡符合此刻剧情；镜头没有以光效大小替代真实的动作后果。
- **局限**：大特效不必然代表更强，弱者也可能虚张声势。可依叙事采用反差；不要求半屏以上，不把满屏高亮当验收标准。写实版本可借人物距离、前景遮挡和姿态表达，而不添加超能力。

## F 翻摔全肢展开

- **适用目的**：交代人物如何失去平衡、被带起、翻转并落到新位置，避免只看到空中姿势却不知道是谁造成的。用于虚构动作表现，不作为真人摔投教学。
- **主体／相机／特效关系**：保持施力者、被带动者及必要的地面同框；选择能分辨身体轮廓和接触关系的景别、方向。被带动者的躯干、四肢、头发和衣物表现相关但有滞后的运动，特效只辅助轨迹，不取代身体。
- **写法示例**：中全景里，两名角色的前臂保持接触，蓝衣角色失去原来的站立平衡，身体随对方转身被带起，越过腰侧后落向画面右侧软沙地。镜头沿横向轻移，始终看见两人的身体与落点；衣摆稍后跟随翻转方向摆动，落地后两人分开。
- **静图／视频**：静图选失衡、翻转中或落地后一个阶段，交代谁在上、谁接地、哪里仍接触；视频需要连接接触、重心改变、翻转和落地状态。复杂接触反复失败时，先用可接受的姿态图／简洁预演确认关系，再减少动作段内的并发变化。
- **验收点**：可辨两人的肢体归属；身体没有互相融化；翻转有前因、落点有后果；关节姿态合理；衣物方向不与运动无因相反；下一镜站位继承结果。
- **局限**：来源“全肢展开／连续弧线”只能作为动作轮廓提示，不要求所有关节伸直、每一肢体同向。合理屈曲和保护性收束不应被删掉。单张漂亮腾空图不能证明全过程可信，实际动作连续性仍需视频验证。

## G 元素对称对峙

- **适用目的**：暂时保留胜负悬念，呈现双方接近的视觉份量。适用于故事此刻确实需要对峙或试探，不给所有战斗强加双方蓄力停顿。
- **主体／相机／特效关系**：双方占据可辨的相对位置，姿态和效果构成左右或对角呼应；通过面积、明暗、密度的总体平衡表现对等，但保留各自不同的形状和节奏。相机稳定或适度移动，不能让位置关系因运镜变得不明。
- **写法示例**：宽阔平台上，两人分别位于画面左前与右后，之间留出清晰空地。左方周围是缓慢上升的银色细流，右方是贴近身体的暗金颗粒，两边亮度和范围相近。镜头平稳观察，他们只调整站姿，没有立即发动攻击。
- **静图／视频**：静图平衡视觉份量而不是复制同一角色；视频允许呼吸、衣物和各自特效有细微差异，维持悬而未决直到已定转折。环绕仅在确能保持轴线、背景和身份关系时作为选项。
- **验收点**：两人未镜像成同一个人；特效各有身份；中间距离可读；视觉没有意外提前揭示单方面碾压；如移动机位，可持续追踪谁在何处。
- **局限**：平衡不等于严格像素对称，更不等于真实力量相同；暗藏优势应依据剧本保留。无需全程对称，不强制冷暖互补，也不将某种环绕范围设为全题材硬上限。

## H 角色签名地面

- **适用目的**：用环境留下的独特痕迹表达控制权、战斗结果或能力余韵。适合角色能力与地面确有关系的情节，不替每个角色自动发明元素领域。
- **主体／相机／特效关系**：选择能看见人物位置和地面分布的较高或斜俯机位；痕迹从明确作用处形成，材质和形状呼应已确认能力。地面变化包围、阻隔还是仅残留，应分别描述，不把视觉包围自动当成真实囚禁。
- **写法示例**：斜俯构图中，白衣角色站在石庭中央，薄霜沿她先前落脚处向周围石缝铺开；对手停在画面右侧尚未结霜的窄路边。镜头缓慢拉开，显示霜纹的范围和仍可通行的位置，双方衣服与身份保持不变。
- **静图／视频**：静图展示某一范围的痕迹及人物与它的关系；视频交代痕迹如何生成、停止或消退。若作为战后收束，记录下一镜是否保留，而不是每次切镜恢复原地面。
- **验收点**：地面变化具有角色归属和发生依据；人物脚底未被纹理覆盖吞没；范围与上一阶段对应；对手是否受限和是否仍有出口可读；后续连续性有记录。
- **局限**：地面染色不是唯一方法，可以是裂纹、残留水迹、散落材料或能力已设定的痕迹；普通生活场景可以不调用。避免为了“签名”破坏用户已接受的场景资产、擅定胜负或将地面变化扩展成全场景换色。

## 来源后续三项扩展（不属于原八类）

同一归档的 `SKILL.md` 在 A–H 后增加了 I–K，交接包八类摘要未包含它们。下面给出可独立使用的简要重述，不将八类悄悄改名为十一种“行业标准”。只有相关动作确属用户情节时选用。

### I 攻击部位推进特写

- **用途与关系**：突出逼近的威胁；以拳、足或武器的可辨表面作前景，相机正向或稍偏观察，背景保留必要来向。主体推进与相机推进分开写，避免同时极端运动而失去接触位置。
- **写法示例**：近景中，角色的拳头沿镜头左侧前方快速逼近，袖口和持拳手臂仍可辨认；相机保持稳定，在尚未遮满画面时切到双方同框，交代对方抬臂挡下这一击。
- **静图／视频与检查**：静图只取逼近中的一刻；视频需要下一段接触或避让兑现这次攻击。检查部位归属、方向与后续落点；不把冲向摄影机等同命中对手。
- **限制**：畸变、巨大前景和快速遮挡会降低辨识度，必要时退回较宽构图；不指定固定停机距离、必须速度线或固定切镜时刻。

### J 上勾动作的蓄力—发力—结果

- **用途与关系**：对确有向上攻击的虚构动作，区分准备、向上运动及对手反应；相机需看清身体与攻击方向，不以爆光跳过接触。此处是画面时序设计，不是人体攻击教程。
- **写法示例**：双人中景中，前景角色由收势转为一次向上出手，后景角色的护臂在胸前接住，随后身体后移一步。镜头轻微上移保持两人上身可见，手臂分开后再确认各自站稳。
- **静图／视频与检查**：静图从三个阶段选一；视频说明来向、接触和结果一致。检查角色位置未互换，护臂接触没有凭空变成身体穿透，运动结束状态可衔接。
- **限制**：来源的腹部重击、弓身击飞是特定动作结果，不是任何上勾动作的必然结果；本扩展保留三阶段表达方式，实际目标与伤害程度按用户情节，不强制腹部变形、击飞或定格。

### K 重拳力量交换链

- **用途与关系**：讲清双方来回交换攻势，而不是一团无法判断归属的挥拳与光效。以当前进攻者→对方防守／受击反应→回应者的次序组织，可跨镜也可在同一稳定构图内完成。
- **写法示例**：两人保持同框，左方先出拳，右方抬臂挡住并退半步；左方收回后，右方回应一次横向挥拳，左方侧身避开。镜头横向轻跟双方位移，末尾保留他们重新拉开距离的状态。
- **静图／视频与检查**：单张静图只能表现其中一轮交换；若交付分镜组，每帧标清谁在进攻和谁在回应。视频检查同一次命中未跨镜重复、动作归属未对调、特效和音效时机与真实接触对应。
- **限制**：不强制四帧、每人必须受击、拳头必须互撞、血珠或面部特写。密集动作失败时减少单段交换次数，仍保留完整因果，不靠添加受伤细节替代动作清楚。

## 输出自查与失败修订

1. 能用一句话说明本段的叙事目的，而不是只报模式字母。
2. 人物动作、相机动作、特效动作分得清；时间顺序、接触位置、归属和段末状态一致。
3. 静图正文只描述一个时刻；视频正文保留动作因果，实际参考图与所写起始状态匹配。
4. 特效太满先减少遮挡和同时发生的变化；身体关系不清先核姿态、接触、落点；方位失控先稳定观察角度，再决定是否需要复杂运镜。
5. 接触图已经错误时优先补图；单帧正确但动态断裂时调整动作段和承接描述。每次说明改动针对什么失败，不能把“增加细节”当成唯一修复手段。
6. 本文完成的是方法层说明。某个模型对接触、摔投、粒子、精确路径的执行能力，需用实际生成素材单独验证；不承诺“黄金模式”必然提高成片质量。
