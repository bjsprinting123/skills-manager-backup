# Krea2图片提示词

先读[共同约定](references/runtime-contract.md)和[写法与输入职责](references/image-writing.md)。无需其他Skill、模型权重、ComfyUI或原作者的素材库即可编写文字。

## 一句话直达

用户仅描述一张图时，直接完成：识别主体／动作时刻／核心感受 → 合理补充必要构图、环境、光线和材质 → 检查互斥细节 → 给简短中文说明及一段完整提示词。用户只要正文时只给正文。

不要要求先交剧本、分镜、资产清单、工作流JSON或一套参考图。普通可变视觉细节可以提案补充；会改变身份、关系、剧情、指定媒介或重要事实的歧义再问。不能因“少年”自动增加情侣或悲伤。

## 选择任务

| 用户需求 | 做法／按需资料 |
|---|---|
| 无图，一句话生图 | 按[可复制模板](references/templates.md)的单图分支直接写 |
| 角色／造型／道具资产 | 读[资产A](references/methods/A.md)、templates；按用途选图，不强制多视图 |
| 场景／站位／俯视／接触／骑乘静帧 | 读[空间S](references/methods/S.md)，接触时读[动作M](references/methods/M.md)；只画一个时刻 |
| 看图反推／多图融合 | 先实际查看图片，分配身份／服装／姿态／风格／场景职责，遵循image-writing；看不到图就说明，文字方案不冒称已看图 |
| 风格或尺度变化 | 读[专题](references/style-and-scale.md)；保留主体事实，不自动注入巨构／胶片／瑕疵 |
| 表情或镜头构图 | 按需读[表演P](references/methods/P.md)、[镜头C](references/methods/C.md)，提取静态可见状态而非整个动作序列 |
| 用户反馈失败图／要求只改局部 | 读[修订分流](references/repair.md)、image-writing的编辑边界 |
| 多次资产交接 | 读[项目记录](references/project-records.md) |
| 用户明确要求维护本Skill | 读[维护流程](references/maintenance.md)；单条提示优化不自动改Skill |

## 输出检查

1. 用户主体、数量、原文文字、动作和感受仍在；每只手、道具、位置和裁切能在同一帧成立。
2. 光源方向、受光面、阴影与材质可解释；相机参数不能冒充从图片精确测量的事实。
3. 正文自然可读，细节按主次；不凑固定500／700词，不堆跨平台参数尾缀。
4. 参考图给助手看与图进入生成器分别说明；未知编辑／控制入口不承诺保真。
5. 不存在的文件不造引用；执行正文不留下互斥任选项、说明书或未完成变量。

默认英文正文＋中文说明是本包协作选择，不声称中文无效；用户要中文则按要求交付，画面里的中文文字保持原文。用中文说明解释尚未核实的设置，不自动填写采样器／显存／节点。

日常无需联网；模型入口有变化或用户要求研究时再核[官方来源](references/sources.md)。
