# Space / Camera / Previs

## 三种空间不要混

1. world space：房间、街道、人物真实位置与路径。
2. body/interaction space：谁面对谁、接触关系、手脚与道具。
3. screen projection：当前机位里谁在画面左/右、谁遮挡谁。

换机位只改变第3层，不会把世界坐标一起改掉。

## Blocking first

先设计人物和道具如何改变空间：进入、退出、靠近、后退、遮挡、显露、接触、交换位置。摄影机随后选择如何观看。

## Shot sentence

先写整段镜头目的：信息从哪里开始、观众跟谁、什么时候焦点改变、什么动作/声音触发摄影机、最后构图落在哪里。再拆为单个 Shot。

## Camera

按需要写 shot size、camera world position、height、angle、lens feel、depth/focus、composition、movement、movement magnitude/path。

复杂运镜必须有 start composition → trigger → path → focus/occlusion handoff → end composition。

## Axis / eyeline

轴线来自人物/动作关系，不是固定“场景一条线”。跨轴可以，但要有视觉动机或重新建立空间；不要让 world-left/right 和 screen-left/right互相替代。

## Previs trigger

多人长镜头、复杂打斗、跨房间移动、复杂 camera path、多人遮挡时优先做 top view / clay board / camera path / animatic。简单文戏不强制宫格。

## Cut motivation

切点来自信息、动作、视线、声音、遮挡、节奏与状态变化。不要为了景别多样性机械切。
