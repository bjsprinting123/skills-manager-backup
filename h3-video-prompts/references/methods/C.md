# C 镜头与衔接（11卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| C01 | 本镜信息任务与景别/切点理由 | 停留、环境、反应都是合法任务；不为凑条数增加镜头 |
| C01a | 先选镜头语法，再形成可执行分镜 | 检查必要状态、来源、时序和声音；无字幕作品不强制先做字幕 |
| C02 | 相机路径、看向目标、主体运动分别写 | 固定相机不等于世界静止；不混用推拉、变焦、摇摄与转轴 |
| C02a | 整段摄影节奏与各镜主要运动 | 复杂行动常需更清楚取景，但“越复杂越稳定”不是不可破的禁令；保留用户指定技巧 |
| C03 | 预演/关键帧/动态各自职责，首尾还要核叙事事实 | 动作完成不等于结局含义成立；末帧一致不保证中间运动正确 |
| C03a | 稳定风格母体与本场变化分层 | 不夹入无关角色/地点；保留事实一致，不强制所有工具逐字重复一长句 |
| C03b | 角色、场景、颜色、音色等锚定与引用唯一性 | 图和描述共同检查；色卡按需，不把“只靠参考、不靠描述”当原理 |
| C03c | 按动作、视线、声音、遮挡、形状或情绪设计接点 | 按需读取本包[二十项转场参考](../transitions-20.md)；各接口写自己的成立条件，硬切不要求有人挡镜或渐显 |
| C03d | 区分镜头、剪切和一次生成单元 | 是否能镜内多切由实际工具决定；文稿需标清编号段里的额外切点 |
| C05 | 解说/B-roll图解的顺序、因果、分支、层级等关系 | 仅相关任务使用，字幕动效不是人物表演通用规则 |
| C06 | 一场的主镜、插入、反应、空间与特殊机位覆盖 | 以信息缺口选择，不强制每场五件套；单一长镜头同样合法 |

## v0.1.2 增补（2026-09-09）

本节为候选增补，数字均为可覆盖的设计默认值；来源为第三方作者报告或设计借鉴，未视为本地实测。


### C12 人物出现节制
- 人脸是稀缺资源。非人物镜头（空镜、物件、环境、局部）的设计默认带宽为30%–50%，可按题材覆盖。
- 连续四个含人脸镜头时，检查是否需要插入非人物镜头；每个非人物镜头回答：服务剧情吗？删掉会损失什么？换成人脸会失去什么？
- 交付前逐镜标注人物/非人物并检查连续段。

### C13 情绪反规则
- 基础规则之外，可有理由地反着用：绝望时拉远、震撼时固定特写、暴力时切空镜、阴险时平视、恐惧时仰拍施暴者。
- 使用时写明叙事理由；反规则是备选，不连续堆叠。
