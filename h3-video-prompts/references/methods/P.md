# P 表演（12卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| P01 | 关注→接收→选择→可见回应 | 角色知情先后与观众呈现顺序分开；别先演结果再补不存在的触发 |
| P01a | 接触动作的触发、回应、结果及后续持有/释放状态 | 不强制每次松手；持续拥抱、握持也合法。不同通道可并行，同一人互斥行动不可重叠 |
| P01b | 必要反应的先后与视线落点 | 例子中的蹙眉和转头顺序不是通用表演序列，幅度依景别判断 |
| P02 | 原状态、变化、停留与余韵 | 情绪不必每拍升级，不为少年喜悦补哭腔或忧伤 |
| P02a | 分配人物、环境、注意力和构图的变化节奏 | 允许静止；不要求每拍必须有动作。不同对象可用不同运动节奏 |
| P02b | 长期行为档案与当场适配 | 只给重要角色建立必要信息，不每镜强贴全部背景和习惯 |
| P02c | 行为受限时选择其他可行表达 | 能量转移是选项；有理由的静止或习惯中断不应被强制替换为敲手指 |
| P02d | 内心动机/不发声独白辅助表演设计 | 不是自动旁白；是否进入生成提示、是否被误念出需另核 |
| P03 | 细节与景别、清晰度、时长相匹配 | 不在小远景里要求逐个毛孔和精细口型，不虚构精确控制能力 |
| P03a | 画面动作与声音事件可分别读取 | 物理分栏或语义分层均可；不能分开后丢掉时间联系 |
| P04 | 需要转变时写旧状态残留、触发、变化和新状态 | 四段式是分析工具，不必每场都发生相反情绪争夺 |
| P05 | 群像的主动者、接收者、焦点及视线网络 | 通常错峰；仪式、齐舞、共同欢呼可以同步，路径交叉也可有意设计 |
