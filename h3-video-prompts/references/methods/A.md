# A 资产（10卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| A01 | 身份、造型、当下状态分开 | 转头/微笑不是新身份；相似外貌也不等于同一人 |
| A02 | 逐素材的用途、继承与不继承范围 | 最少充分，不默认全套视图；素材未提供不编引用 |
| A02a | 参考职责、可见状态、辨认锚点与禁区 | 身份/姿态/比例/首帧是不同职责；同一文件可以承担多职，但要明确，不绝对禁止复用 |
| A02b | 区分身份结构参考与风格/光线参考 | 中性参考是常用选择；风格化角色可保留自身画法，不一律排除全部风格 |
| A02c | 需要写实时按物理状态、区域纹理、瑕疵、高光、光线与时间描述皮肤 | 不强制两处缺陷；洁净皮肤、动画材质和远景有不同需求 |
| A03 | 记录状态变化、接受版本及受影响镜头 | 计划与实际分开；持物可属于造型或动作状态，按是否需要变化处理 |
| A03a | 优先保留已认可区域，局部修图留版本 | 整图重做有时必要；“重绘两次必坏”不是已验证规律 |
| A03b | 检查图文、跨角度及与场景组合后的身份/比例/结构 | 测试数量按需要，不用作者“90%”或“十次全过”代替证据 |
| A04 | 声音身份描述、可变说话状态及可用音频参考 | 音频参考按需且需合法可用；不要把固定身份写成永不改变的音量和语气 |
| A05 | 从剧情找叙事、环境、身份与隐含道具，并追位置/持有人/状态 | 按重要性建卡；十三字段和某套编号是实现选项，不是人人都要填的资产表 |

## v0.1.2 增补（2026-09-09）

本节为候选增补，数字均为可覆盖的设计默认值；来源为第三方作者报告或设计借鉴，未视为本地实测。


### A11 参考素材权威声明
- 每个素材声明负责什么、不负责什么；外观权威不自动继承动作、取景、环境、声音或剪辑权威。
- 同一素材可承担多个职责，但逐项声明；素材冲突时按用户最新显式决定裁决。
- 视频音轨默认不启用，除非显式声明。
