# R 组织、交付与修订（10卡）

| 卡号 | 要写/产出 | 核对与条件 |
|---|---|---|
| R01 | 命名约束、优先级与冲突消解 | 突出最关键几项，不以“≤3”删掉必要事实或安全边界 |
| R02 | 当前任务→实际参考与起点→空间/机位→动作与声音→结束状态及限制 | 原字段是检查菜单，不强制固定顺序或独立负面框；保留逐镜五问 |
| R03 | 分清故事长度、镜头长度、工具生成单元 | 先保证叙事和容量，再按用户工具取舍；上限、引用方言不入通用常量 |
| R04 | 本阶段实际可交付文件、编号、来源与状态索引 | 默认交付文字包；媒体按实际授权登记。整片裁切可用，但不得冒充独立生成、可编辑或已验收资产 |
| R05 | 让用户在自己的工具里继续：说明文件用途与接续状态 | 有分轨/字幕/工程才交相应文件，没有时给方案而不假造；不承诺格式导出已实现 |
| R06 | 选择剧本先行、逐段探索或混合组织方式 | 已定事实与探索提案分开，不把第一版失败当所有项目必须改流程 |
| R07 | 建立当前场面必要的视觉方向、角色/声线、空间与色彩约定 | 不一次性强制字体、全部档案、色卡和全片资产；与A02最少充分一致 |
| R08 | 知识卡保存方法、适用、目的、步骤、可选参数、反例及来源 | 参数缺依据时不补造；同源转述不算独立复现 |
| R09 | 检查描述具体、机位自洽、声源清楚、状态/引用无冲突、结尾容量够用 | 不强制“轻微＋呼吸”、两处瑕疵、单人静止结尾或所有技术值精确化 |
| R10 | 用户点名技巧的效果、触发、起终画面、相机/主体变化、保持项及替代方案 | 技巧可以是镜头主任务；若不兼容，说明取舍，不静默改成普通覆盖镜头 |
