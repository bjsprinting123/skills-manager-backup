# Visual Bible

## Visual Development 的职责

回答“整部作品为什么长成这个样子”，而不是“这一镜用什么漂亮 Prompt”。

## Production Design

建立 era/culture、architecture、room/street logic、furniture/dressing、props、materials、typography/graphic policy、recurring motif。空间应有使用痕迹和人物关系，不只是“豪华”“破旧”。

## Character Look

分 identity、silhouette、costume、hair、makeup、age、injury/dirty/wet、story-state variants。服装可以随着人物关系/身份/阶段变化，但每个变化要有故事原因。

## Palette

明确 base colors、character colors、location colors、accent/motif、禁止冲突。Palette 不是 LUT。

## Color Script

记录 story stage → color/light state → narrative reason。颜色随故事变化，而不是每一场随机换“电影色调”。

## Lighting concept

项目级先定 motivated source、natural/artificial balance、day/night、contrast、color temperature logic、practicals、story-driven changes；Shot 层再根据机位落实具体受光。

## Look / texture

可规定 saturation、contrast、black level、highlight rolloff、grain/texture、sharpness、skin/material response。写机制，不靠 8K/masterpiece。

## Color Grade

后期 Grade 继承 Visual Bible / Color Script：先 shot matching / exposure / balance，再 approved creative grade，最后 delivery transform。Grade 不重新发明另一部电影的风格。
