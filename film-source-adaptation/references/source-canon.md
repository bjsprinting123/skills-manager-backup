# Source Canon / Adaptation

## Source 不是“现实真相”的同义词

Source 可以是原创灵感、个人经历、他人经历、小说/短篇、历史/纪实材料、大纲、完整剧本或混合材料。Source Canon 表示当前作品采用的权威来源状态，不等于声明现实世界事实。

## 四类信息

- accepted facts：材料明确给出，当前创作接受。
- must preserve：改编不允许改变。
- flexible：允许压缩、合并、重排、改写。
- unknown：来源没有提供，不能被下游自动脑补成事实。

## 长篇小说

优先顺序：章节索引 → 逐章/分块功能 → 剧情单元 → 人物/关系/世界合并 → 改编价值 → 分集候选。

保留来源 span / 章节位置，并区分 screen-ready action、说明性 prose、可合并情节、不能丢的因果与重复信息。抽样研究必须标抽样，不写成全量结论。

## 真实经历

区分用户明确记得、用户不确定、为戏剧结构提出的创作提案。事实不完整时不自动补成确定事实。

## 完整剧本 takeover

已有完整剧本时不强制回退 Synopsis/Treatment；保留作者正文与场次，只补制作需要的版本、场次、角色、资产、时长等元数据。只有用户要求重写时才回 Story/Screenplay。

## Rights / provenance

至少记录来源、版本/日期、可公开边界、是否用户拥有/授权、第三方版权风险、哪些内容只能内部研究。来源记录不等于自动获得商用许可。
